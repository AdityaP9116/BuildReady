## WebMCP-specific work

- Implemented page-owned tools using `document.modelContext.registerTool`.
- Added strict schemas and tool descriptions grounded in visible workflow state.
- Used `readOnlyHint` and `untrustedContentHint` according to behavior and provenance.
- Re-registered tools conditionally as inspection, proposal, decision, simulation, quotes, and package state changed.
- Aborted route/state-obsolete registrations and verified no duplicates.
- Kept approval out of the tool surface to demonstrate explicit human authority.
- Tested tool visibility and behavior in ChatGPT's in-app browser.

## Pre-existing work

None of the implementation predates the challenge repository. The manufacturing scenario was shaped from project research during the challenge. All geometry, rules, supplier fixtures, copy, and UI assets are original controlled demonstration content unless identified in `THIRD_PARTY_NOTICES.md`.
